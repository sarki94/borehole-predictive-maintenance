# Data Directory

Place `pump_sensor.csv` in this folder before running any notebook.

## Download

**Browser:** https://www.kaggle.com/datasets/nphantawee/pump-sensor-data  
**CLI:** `kaggle datasets download -d nphantawee/pump-sensor-data --unzip -p data/`

## File expected by notebooks

```
data/
└── pump_sensor.csv   (~19 MB, 220,320 rows × 54 columns)
```

The CSV is excluded from this repository via `.gitignore`.
